# VLM-RAG 项目结构说明

## 目录整理原则

- 保留现有数字序号命名，例如 `__000__django`、`__001__rag`、`__011__frontend`。
- Django app、接口模块、导入路径不做重命名，避免破坏运行和迁移。
- 文档统一归档到 `__000__doc`，按用途继续使用数字序号分类。
- 运行数据、初始化数据、脚本、容器配置分别放在 `data`、`scripts`、`docker` 等支撑目录。

## 核心代码目录

| 目录 | 说明 |
| --- | --- |
| `__000__django` | Django 项目配置、路由、Celery、全局中间件 |
| `__001__rag` | RAG 核心模型、租户上下文、审计、任务、用量、反馈等基础能力 |
| `__002__kb` | 知识库接口、知识库 ACL |
| `__003__document` | 文档上传、文档管理、解析与索引入口 |
| `__004__chunker` | 文档切分与分块策略 |
| `__005__conversation` | 会话、问答、会话导出 |
| `__006__llm` | 模型厂商、模型配置、API Key 加密、轮换记录 |
| `__007__rag_conf` | 检索策略配置 |
| `__008__intention_type` | 意图分类相关能力 |
| `__009__ner_dict` | 实体词典相关能力 |
| `__010__colpali` | 多模态页图检索与视觉 RAG 能力 |
| `__011__frontend` | 前端页面和静态资源 |
| `__012__tenant` | 租户、用户、角色、配额等管理接口 |
| `__013__ops` | 运维治理、健康检查、内容安全、告警、质量与成本看板 |
| `__014__evaluation` | 评测集、评测执行、评测结果 |
| `__015__auth` | 登录、当前用户、退出等认证接口 |

## 文档目录

| 目录 | 说明 |
| --- | --- |
| `__000__doc/__000__project_docs` | 项目结构、架构说明、开发说明 |
| `__000__doc/__001__requirements` | 业务需求清单、分期规划 |
| `__000__doc/__002__testing` | 业务测试文档、实验验证文档 |
| `__000__doc/__003__operations` | 环境启动、部署、初始化、运维说明 |
| `__000__doc/讲义` | 课程讲义 |
| `__000__doc/legacy_jarvis` | 历史参考工程归档，不作为当前主入口 |

## 支撑目录

| 目录 | 说明 |
| --- | --- |
| `data` | SQLite、本地初始化数据、上传文件、运行数据 |
| `docker` | Docker 相关配置 |
| `logs` | 本地运行日志 |
| `scripts` | 初始化、启动、检查、备份、恢复脚本 |
| `tests` | 自动化测试 |

## 当前主入口

- 后端入口：`manage.py`
- 前端入口：`__011__frontend/index.html`
- 环境启动文档：`__000__doc/__003__operations/环境启动文档.md`
- 业务测试文档：`__000__doc/__002__testing/业务测试文档.md`
- 需求清单：`__000__doc/__001__requirements/vlm-rag需求清单.md`
