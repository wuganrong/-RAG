# VLM-RAG 业务测试文档

## 1. 测试目标

验证当前前端页面是否覆盖现有业务，并确认核心业务链路可走通：

```text
租户 -> 用户角色 -> 模型厂商 -> 模型 -> 知识库 -> 文档上传 -> 文档解析 -> 检索调试 -> 问答 -> 引用 -> 反馈 -> 评测 -> 用量统计 -> 审计日志
```

访问地址：

```text
http://127.0.0.1:9380/
```

默认用户：

```text
admin
```

默认租户：

```text
default
```

## 2. 基础数据检查

打开页面后检查：

- 顶部租户下拉存在 `默认租户 (default)`
- 顶部用户 ID 默认为 `admin`，点击“登录”可以获得登录 Token
- “模型管理”能看到默认模型
- “厂商配置”能看到 `Tongyi`
- “用户权限”能看到 `admin / editor / viewer`

验收标准：

- 页面没有明显 JS 报错
- 接口没有连续 500 错误
- 种子数据能正常展示

实测（2026-09-17）：通过。控制台可访问，种子数据展示正常。Rerank 模型为 `qwen3-rerank`。厂商 Key 脱敏 `sk-e****fd1f`。

登录认证基础测试：

1. 顶部用户 ID 输入 `admin`
2. 点击“登录”
3. 页面提示登录成功
4. 设置强认证模式后，接口可通过 Bearer Token 访问

