# VLM-RAG 生产级需求清单

## 1. 产品定位

VLM-RAG 定位为面向企业、组织或团队的多租户多模态知识库智能问答平台。

平台核心能力是将 PDF、Word、PPT、图片、扫描件、表格等知识资料接入系统，通过文本 RAG、视觉 RAG、混合 RAG、模型管理、权限控制、会话留痕、引用溯源、反馈评估等能力，为用户提供可解释、可审计、可运营的知识问答服务。

## 2. 核心业务目标

- 支持企业或团队按租户隔离知识资产、模型资源和会话数据。
- 支持统一管理 LLM、VLM、Embedding、Rerank、OCR、文档解析等模型能力。
- 支持知识库从创建、配置、授权、文档接入、解析索引到问答使用的完整生命周期。
- 支持复杂 PDF、扫描件、图表型资料的多模态检索与问答。
- 支持文本引用、页图引用、文档来源、页码和命中依据展示。
- 支持用户对问答结果进行反馈，沉淀质量评估数据。
- 支持用量、成本、审计、安全等生产级运营能力。

## 4. 租户管理

### 4.1 业务说明

租户是平台最高层级的数据隔离单位。一个租户可以代表一个企业、部门、项目组或客户组织。

### 4.2 功能需求

- 创建租户。
- 编辑租户信息。
- 启用或禁用租户。
- 删除或归档租户。
- 管理租户成员。
- 配置租户资源配额。
- 配置租户可用模型。
- 查看租户用量和成本。
- 查看租户下知识库、文档、会话、模型配置等资源。

### 4.3 核心字段

- tenant_id
- tenant_name
- tenant_code
- status
- owner_user_id
- storage_quota
- document_quota
- token_quota
- vision_page_quota
- created_at
- updated_at

### 4.4 生产级要求

- 所有核心业务数据必须带 tenant_id。
- 不同租户之间的数据不可互相访问。
- 租户级 API Key、模型配置、知识库、文档、会话必须隔离。

## 5. 用户与角色权限

### 5.1 业务说明

用户是平台实际操作者。用户必须归属于租户，并通过角色控制功能权限和数据范围。

### 5.2 功能需求

- 用户登录、登出。
- 用户所属租户管理。
- 邀请成员。
- 移除成员。
- 启用或禁用用户。
- 配置用户角色。
- 查看用户操作记录。

### 5.3 建议角色

- 租户管理员：管理租户、成员、模型、知识库和统计。
- 知识库管理员：管理知识库、文档、解析和索引。
- 普通用户：使用授权知识库进行问答。
- 只读用户：查看知识库和会话，但不能修改资源。

### 5.4 权限范围

- 是否允许创建知识库。
- 是否允许上传文档。
- 是否允许删除文档。
- 是否允许修改模型配置。
- 是否允许查看会话记录。
- 是否允许导出数据。
- 是否允许查看统计报表。

- 按租户分配可用模型。

- 查看模型调用统计。
- 配置模型调用参数。
- 配置模型失败降级策略。

## 10. 检索策略管理

### 10.1 业务说明

检索策略决定 RAG 的召回质量，是知识库问答准确性的关键。

### 10.2 文本检索策略

- 向量检索。
- 关键词检索。
- 混合检索。
- 多路召回。
- Rerank 重排。
- 相似度阈值。
- 文本召回 TopK。
- 最终上下文 TopN。

### 10.3 视觉检索策略

- ColPali 页图检索。
- 页图 TopN。
- 是否返回页图。
- 是否将页图交给 VLM。
- 是否结合 OCR 文本。

### 10.4 混合 RAG 策略

混合 RAG 是指一次提问同时使用文本检索和视觉页图检索，再将文本 chunk 和页图证据共同交给模型生成答案。

可配置策略包括：

- 文本优先。
- 视觉优先。
- 文本与视觉共同输入。
- 按问题类型自动路由。
- 图表型问题优先视觉检索。
- 纯文本问题优先文本检索。

### 10.5 查询增强策略

- Query rewrite。
- 多查询扩展。
- 意图识别。
- 知识库路由。
- 关键词抽取。

## 14. 反馈评价

### 14.1 业务说明

反馈评价对象是某一次回答，不是单独的问题。反馈用于评估回答质量、检索质量和引用质量。

### 14.2 功能需求

- 对回答标记有用或无用。
- 标记答案正确或错误。
- 标记引用相关或不相关。
- 标记回答完整或不完整。
- 填写用户备注。
- 选择反馈原因。

### 14.3 反馈原因

- 答案错误。
- 没有命中文档。
- 引用不相关。
- 回答太泛。
- 图表理解错误。
- 漏掉关键信息。
- 幻觉回答。

### 14.4 质量统计

- 知识库命中率。
- 回答满意率。
- 引用相关率。
- 无答案率。
- 失败率。
- 不同 RAG 模式效果对比。
- 不同模型效果对比。
